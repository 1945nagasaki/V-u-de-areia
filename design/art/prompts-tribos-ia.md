# Prompts para IA de imagem — as sete tribos e os sete líderes

Fonte: o prompt-mestre do autor (2026-11-18, "AAA 3D Game Character &
Environment Design… Strict No-Live-Animals Constraint"), dividido em **14
prompts independentes**:
- 7 de tribo: aldeões + aldeia + paleta;
- 7 de líder: personagem + relíquia.

Cada prompt é autossuficiente: a IA de imagem não "lembra" do anterior, então o
estilo vai repetido em todos.

## Como usar

- Os prompts estão em **inglês**. As IAs de imagem seguem melhor assim.
- O tamanho foi pensado para caber no limite útil de Midjourney, DALL·E 3 /
  GPT-Image, Flux e Stable Diffusion (cerca de 150–200 palavras).
- **"Sem animais vivos"**: escrever "no animals" no prompt costuma fazer a IA
  desenhar animais, porque ela "vê" a palavra. Use o campo próprio de cada
  ferramenta:
  - **Midjourney:** cole o sufixo `MJ` no fim do prompt.
  - **Stable Diffusion / Flux (com campo negativo):** cole a linha `NEGATIVO`
    no prompt negativo.
  - **DALL·E / GPT-Image (sem campo negativo):** o prompt já termina com uma
    frase positiva ("the only animal matter is crafted…"), que funciona melhor
    que "no".
- **Canibalismo** (cânone desde 2026-11-18): aparece **implícito**, com pilhas
  de ossos, crânios em totens, ganchos de açougue vazios e sangue velho.
  Nunca há corpos nem gore explícito. Isso segue a regra do autor ("sem
  violência gráfica gratuita") e passa na moderação das IAs, que bloqueiam
  canibalismo explícito.

```
MJ:       --ar 16:9 --style raw --v 7 --no live animals, wildlife, birds, dogs, horses, cattle, creatures, corpses, gore, text, watermark
NEGATIVO: live animals, wildlife, birds, dogs, horses, cattle, insects, creatures, monsters, corpses, dismemberment, explicit gore, cartoon, anime, low poly, toy, plastic, text, letters, watermark, logo, blurry, deformed hands, extra fingers
```

### Cuidados com as referências reais

As relíquias são **inspiradas** em tradições artísticas reais:
- Fang;
- Sango;
- Chokwe;
- Bronzes de Benim;
- Cabeças de Ifé;
- Kota;
- Sika Dwa Kofi.

São objetos ficcionais, não reproduções históricas. As tribos são facções
inventadas. Os prompts não usam nomes de povos reais e não associam essas
tradições ao canibalismo. Duas referências pedem cuidado:

- **Sika Dwa Kofi** (o Banco de Ouro Axânti) ainda é sagrado.
- Os **Bronzes de Benim** estão no centro de pedidos de restituição.

Ao divulgar as imagens, vale manter a legenda "inspirado em".

## Pontos em aberto contra o cânone

O prompt-mestre bate com a tabela das tribos (`design/narrative/README.md`)
em pecado, líder, animal, bioma e relíquia. Algumas diferenças precisam de
decisão do autor:

- **Canibalismo:** o autor confirmou que é cânone, mas os sete documentos das
  tribos ainda não falam disso. Falta incorporar nas partes de Cultura e
  Comportamento.
- **Comportamento com estranhos:** é novo e está nos prompts. Ainda não está
  nos documentos nem no jogo.
  - Coroa-Alta e Mão-Cerrada matam quem chega.
  - Brasa-Viva e Pouso-Lento atacam quem invade.
  - Véu-Carmesim e Mesa-Farta só reagem se provocados.
  - Espelho-Turvo arma emboscadas.
- **Onkuisheid "traído e fragmentado nas relíquias":** o README pede para
  preservar a relação com Akin "sem criar uma segunda entidade". Como foi
  escrito, o prompt pode sugerir que Onkuisheid **é** Akin. No prompt do líder
  isso ficou só como "a sensação de que falta algo nele" até o autor decidir.
- **Afguns "obcecado em destronar Akin":** o cânone diz "quer reencontrar Akin
  para desafiá-lo". São compatíveis; o prompt usa "destronar".
- **Sem animais vivos:** vale para estas imagens de conceito. O jogo tem fauna
  viva (guardiões dos biomas, animais de caça) e isso não muda.
